📘 1. Мини-лекция

Машинное обучение (ML) — направление искусственного интеллекта, при котором алгоритм учится находить закономерности в данных и использовать их для новых случаев.

✍️ ОБЯЗАТЕЛЬНО ЗАПИШИ В ТЕТРАДЬ 8 ПУНКТОВ ИЗ ЛЕКЦИИ:
  1. Машинное обучение — обучение алгоритма на данных.
  2. Данные — информация, на которой обучается модель.
  3. Признак (feature) — характеристика объекта, используемая моделью.
  4. Целевая переменная (target) — результат, который модель должна предсказать.
  5. Обучающая выборка — примеры, используемые для обучения.
  6. Модель — математическое представление закономерностей, найденных в данных.
  7. Обучение с учителем — обучение на примерах с известными правильными ответами.
  8. Обучение без учителя — поиск структуры и закономерностей без заранее известных ответов.
Важно: модель не «понимает» данные как человек. Она выявляет закономерности по примерам.
