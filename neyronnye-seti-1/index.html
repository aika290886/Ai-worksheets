📖 1. Подробный конспект

1.1. Зачем нужны нейронные сети?

Компьютер хорошо выполняет точные инструкции. Но есть задачи, где трудно заранее записать все правила. Например, определить, есть ли на фотографии кошка. Кошка может быть маленькой, боком, в темноте или частично закрыта.

Вместо того чтобы вручную прописывать тысячи правил, можно использовать модель, которая учится находить закономерности по данным и примерам.

Главная идея: нейронная сеть не «думает» как человек. Она выполняет математические вычисления над данными и использует найденные закономерности для получения результата.

1.2. Что такое искусственная нейронная сеть?

Искусственная нейронная сеть — математическая модель из связанных между собой искусственных нейронов. Она получает входные данные, обрабатывает их и формирует результат.

1.3. Что такое искусственный нейрон?

Искусственный нейрон — вычислительный элемент сети. Он получает несколько входных сигналов, учитывает их важность, объединяет информацию и формирует выход.

1.4. Почему он называется «нейронным»?

Название связано с биологическими нейронными сетями. Нервные клетки мозга передают сигналы друг другу. Учёные использовали некоторые идеи этого принципа как вдохновение для математических моделей.

Важно: искусственная нейросеть не является копией человеческого мозга. Это математическая модель для обработки информации.

1.5. Что такое синапс?

В биологии синапс — область контакта, через которую один нейрон взаимодействует с другим. Для школьного понимания можно представить его как место передачи сигнала.

В искусственной нейросети есть связи между нейронами. Им назначаются числовые параметры — веса. Вес показывает, насколько сильно конкретный вход влияет на вычисление.

Запомни: синапс — биологический термин. В искусственной сети мы говорим о связях и весах. Это полезная аналогия, но эти понятия не полностью одинаковы.

1.6. Что такое слой?

Много нейронов можно организовать в слои. В простой сети обычно выделяют входной слой, один или несколько скрытых слоёв и выходной слой.

📥 Входной слой
получает данные
→
🧠 Скрытый слой
обрабатывает
→
📤 Выходной слой
выдаёт результат

В сложных моделях скрытых слоёв может быть много. Поэтому говорят о глубоком обучении — использовании многослойных нейронных сетей.

1.7. Как проходит информация?

  1. Данные поступают на вход.
  2. Сигналы проходят через связи.
  3. Нейроны выполняют вычисления.
  4. Результаты передаются дальше.
  5. Выходной слой формирует итог.
Формула для запоминания: данные → входы → обработка → передача сигналов → результат.

1.8. Как нейросеть учится?

В следующих листах мы разберём обучение подробно. Сейчас достаточно общего представления: сеть получает примеры, делает прогноз, сравнивает его с правильным ответом и изменяет свои параметры так, чтобы постепенно уменьшать ошибку.
