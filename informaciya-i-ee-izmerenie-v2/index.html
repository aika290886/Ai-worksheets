5. Алфавитный и вероятностный методы

Алфавитный метод / Алфавиттік әдіс

Если N — число символов алфавита, то информационный вес одного символа X определяется из N = 2ˣ. Объём сообщения: I = K × X.

N = 2ˣ     I = K × X
Найди N — размер алфавита.
Определи X — бит на один символ.
Умножь X на число символов K.
Мини-тренажёр / Мини-тренажер

Вероятностный метод / Ықтималдық әдіс

В учебных задачах определяют число возможных равновероятных событий N и используют N = 2ˣ, где X — объём информации в битах.
