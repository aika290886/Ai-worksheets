3. Подробный конспект

Что такое искусственный нейрон?

Искусственный нейрон — математическая модель, которая получает несколько чисел на входе, учитывает их важность и вычисляет результат. Нейрон не «думает» как человек. Он выполняет последовательность математических операций.

1) Входные значения

Входы x₁, x₂, x₃... — признаки объекта. Например, для определения, является ли изображение кошкой, признаками условно могут быть характеристики изображения. В реальной нейросети таких числовых признаков может быть очень много.

2) Веса

Каждому входу соответствует вес w. Вес показывает, насколько сильно данный вход влияет на итоговую сумму. Больший по модулю вес означает более сильное влияние в данной модели.

3) Взвешенная сумма

Нейрон умножает каждый вход на соответствующий вес и складывает результаты. Часто дополнительно используется смещение b.

z = x₁w₁ + x₂w₂ + … + xₙwₙ + b

4) Функция активации

После вычисления суммы применяется функция активации. Она преобразует значение z в выход нейрона. Для простого учебного примера можно использовать пороговое правило:

если z ≥ 0 → y = 1    |    если z < 0 → y = 0

5) Что такое синапс?

В биологическом мозге нейроны соединены синапсами. В искусственной нейронной сети аналогом связи между нейронами является соединение с числовым весом. Во время обучения веса изменяются, чтобы сеть давала более подходящие ответы.

Запомни: нейрон не получает готовое человеческое решение. Он получает числа и выполняет вычисления. В обучаемой сети параметры, прежде всего веса, постепенно корректируются по данным обучения.
